# Autoflow Core

**Autoflow Core** is a robust, multi-tenant B2B SaaS Automated Omni-Channel Lead Engagement Engine. It replaces brittle visual visual-loop flows in automation platforms like n8n with a central, deterministic Python state machine and high-performance routing matrices.

---

## 🏗️ System Architecture

```
                    +---------------------------------------+
                    |        PostgreSQL Database            |
                    |  - Tenants, Prospects, Audit Logs     |
                    +---------------------------------------+
                                  ▲           │
                     Reads/Writes |           | Ingests Webhooks
                                  │           ▼
+------------------+        +--------------------------------+        +--------------------+
|  OpenRouter API  |◄───────|     Python Backend Engine      |───────►|     n8n runner     |
|  - JSON Mode     |  LLM   |  - State Machine Graph Logic   |  HTTP  |  - Gmail Send      |
|  - Structured    |───────►|  - Cooldown & Channel Routing  |        |  - Phantombuster   |
+------------------+        +--------------------------------+        +--------------------+
```

## 🚀 Quickstart Guide

### 1. Python Backend Setup

Ensure you have Python 3.13+ and [uv](https://github.com/astral-sh/uv) installed.

```bash
# Navigate to backend directory
cd backend

# Create virtual environment
uv venv

# Add and install dependencies
uv add fastapi uvicorn sqlalchemy psycopg2-binary pydantic pydantic-settings openai httpx
```

#### Running the Stress Test Simulator
Our simulation suite spawns two parallel tenants, validates cross-tenant security isolation, registers prospects, steps them through the entire outreach cycle, and injects deliberate copywriting errors (buzzwords, length limits) to prove that safety controls successfully trap them.

```bash
# Execute the test suite from the backend directory
PYTHONPATH=src uv run python3 src/backend/test_simulation.py
```

#### Booting the FastAPI Application
```bash
# Launch the API server
PYTHONPATH=src uv run uvicorn backend.app:app --reload --port 8000
```
Interactive OpenAPI documentation will be available at `http://localhost:8000/docs`.

---

### 2. C++ Logic Analyst Setup

To prepare for high-volume SaaS scaling, the state machine and sequence routing limits are modeled as a native C++ high-efficiency **O(1) Boolean adjacency matrix**.

```bash
# Navigate to logic_analyst directory
cd logic_analyst

# Compile using g++
g++ -std=c++17 main.cpp state_matrix.cpp -o logic_validator

# Run validator assertions
./logic_validator
```

## ⚙️ Environment Variables Config

Create a `.env` or `.env.local` file inside the `backend/` directory to configure credentials:

```ini
# OpenRouter / LLM Config
OPENROUTER_API_KEY=your_openrouter_api_token
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1
OPENAI_MODEL=anthropic/claude-3.5-sonnet

# Database Config (Defaults to local SQLite autogenerated schema)
DATABASE_URL=postgresql://user:password@localhost:5432/autoflow

# n8n Webhook Triggers
N8N_GMAIL_WEBHOOK_URL=https://your-n8n-instance.com/webhook/gmail-outbound
N8N_LINKEDIN_WEBHOOK_URL=https://your-n8n-instance.com/webhook/linkedin-outbound
```

## 🛡️ Core Engine Guardrails

* **Multi-Tenant Security Gate**: The `TenantRepository` checks every query against the `tenant_id` context. If any endpoint tries to query or log outreach details for a prospect that does not belong to that tenant, a `TenantAccessError` is thrown immediately.
* **Copywriting Validation Layer**: When the LLM generates messages, they are run through Pydantic validators. If the model starts a sentence with "I", uses sales jargon (*synergy*, *leverage*, *game-changer*), or exceeds character limits (300 for LinkedIn notes; 500 for emails), the message is blocked, and the prospect is transitioned to the `data_error` state.
